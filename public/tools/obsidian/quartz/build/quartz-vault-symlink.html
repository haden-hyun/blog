Vault 심볼릭 링크 연결하기

Vault 심볼릭 링크 연결하기

Sep 13, 202613 min read

  • tools/obsidian

Summary

  • 심볼릭 링크는 Quartz 프로젝트의 content 폴더가 실제로는 옵시디언 Vault를 가리키도록 만드는 주소표다.
  • 링크를 걸기 전에 기존 content 폴더를 물리적으로 지우고 Git 캐시에서도 제거해야 한다. 캐시가 남으면 빌드가 계속 실패한다.
  • .gitignore에서 public 제외 설정을 풀어야 한다. 로컬 빌드 전략에서 public은 반드시 올라가야 할 결과물이다.
  • ln -s 실행 시 경로는 큰따옴표로 감싸고, 원본 경로 끝에 슬래시(/)를 붙이지 않는다.
  • GitHub에서 content가 파일 목록 없이 경로 텍스트로만 보이는 것은 정상이다. 원격은 로컬 경로를 읽을 수 없기 때문이다.

실습 환경

이 시리즈는 macOS 기준으로 작성했다. 경로 표기(/Users/...)와 셸 명령(ln -s)이 Windows와 다르므로 각자 환경에 맞게 바꿔 읽어야 한다. 이 글은 Quartz v5 기준이다.

들어가며

로컬 빌드와 배포 패러다임에서는 파일 복사의 귀찮음을 없애기 위해 심볼릭 링크(주소표)를 쓰기로 결정했다. 그러나 실제 설정 과정에서는 Git 캐시 꼬임과 경로 설정 실수가 자주 발생한다.

이 글에서는 에러 없이 심볼릭 링크를 걸고 Git과 연동하는 방법을 다룬다.

심볼릭 링크란

심볼릭 링크는 실제 파일 대신 “진짜 파일이 어디 있는지”를 가리키는 주소표다. 작업하는 옵시디언 경로와 Git에 연동할 블로그 폴더 경로를 다음과 같이 나눈다.

  • 원본 폴더: 메인 옵시디언 Vault (/Users/haejun/Documents/obsidian/00-Blog/content)
  • 블로그 폴더: Quartz 블로그 폴더 (/Users/haejun/Developer/haejunhyun.com/content)

Quartz 블로그 폴더 안에 가짜 content 폴더를 만들고, 이 폴더를 열면 실제로는 메인 옵시디언 폴더가 보이도록 연결한다. 이렇게 하면 옵시디언에서 글을 쓰는 즉시 Quartz 블로그 폴더에도 반영된다.

참고로 로컬 개발 환경용 Developer 폴더를 새로 만들었고, 레포 이름은 블로그 도메인(haejunhyun.com)으로 설정했다.

Git 연동 및 초기화

레포 준비와 캐시 제거

심볼릭 링크를 걸기 전에 Git 쪽 정리를 먼저 끝내야 한다. 이 과정을 생략하면 이후 빌드가 계속 실패한다. 특히 content를 GitHub에 한 번이라도 올린 적이 있다면 Git이 캐시를 들고 있다. 심볼릭 링크로 바꿔도 Git은 예전 상태로 착각하므로, 아래 단계가 필수다.

순서는 다음과 같다.

  1. GitHub에서 Quartz 레포를 템플릿으로 가져와 repo를 만든다.
  2. 로컬 블로그 폴더에 git clone한다.
  3. 의존성을 설치한다(npm install).
  4. 기존 content 폴더를 제거한다.
  5. Git 캐시에서도 content를 제거한다.

GitHub에서의 정상적인 모습

심볼릭 링크로 연동한 content를 GitHub에 업로드한다.

GitHub에서의 정상적인 모습

이 커맨드로 심볼릭 링크 정보를 GitHub 원격에 등록한다.

파일 목록 대신 경로 텍스트만 보여도 고장이 아니다

GitHub에서 content를 클릭했을 때 글 목록은 없고 /Users/haejun/Documents/... 같은 경로 텍스트 한 줄만 보이는 것이 정상이다. 링크가 깨진 것으로 오해해 다시 걸 필요가 없다.

GitHub 입장에서는 내 로컬 경로를 들여다볼 수 없으므로, 심볼릭 링크가 가리키는 주소 텍스트만 보여주는 것이 당연하다. 실제 배포는 로컬에서 빌드한 public 폴더가 담당하므로 아무 문제가 없다.

  • 로컬: 이 주소를 이해하고 통로를 따라가 빌드할 수 있다.
  • GitHub/Cloudflare: 이 주소를 읽을 수 없으므로 빌드할 수 없다.

빌드는 로컬에서만 가능하다는 이 성질이야말로 앞 글에서 설계한 로컬 빌드 전략의 전제다.
